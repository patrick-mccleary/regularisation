# regularisation
Regularisation is a process used to treat linear inverse problems of the form $\mathbf{A}\mathbf{x} = \mathbf{b}$ by deliberately introducing bias for a significant increase in stability. However, regularisation is commonly treated as a ``black-box'' default that is blindly applied in machine learning --- this is problematic because its application is not benign. Unnecessarily regularising a system introduces bias without the need for added stability and suppresses meaningful features, while silently masking this misapplication by returning a finite output. This project explored the mathematical criteria that necessitate regularisation and applied these conditions to common machine learning datasets. 

The condition that determines whether regularisation is required is the qualitative shape of the L-curve. Testing was conducted on the ill-posed Tecator dataset and the well-posed California housing dataset to determine if regularisation was required, and if so, how to select the optimal model. The importance of a diagnostic step prior to application was emphasised, as this helps inform model decisions. The lasso technique yielded the most accurate and stable predictive model whilst using the fewest features, a result that was validated with known physical data. Furthermore, the L-curve was established to be a more robust parameter selection method than the GCV. Ultimately, this project showed the dangers of default application of regularisation and outlined a proposed automated diagnostic step in an attempt to solve this problem for future use in machine learning pipelines.
